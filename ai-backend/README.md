# ИИ-агент (Flet + YandexGPT)

Здесь лежит ваше Flet-приложение `flet_app.py`, развёрнутое как веб-сервис.
На сайте оно показывается через `<iframe>` — выглядит и работает точно
так же, как в приложении на компьютере, только внутри окна на странице.

## Прежде всего — перевыпустите ключ

Ключ, который раньше был написан в коде, уже "засвечен". Зайдите в
консоль Yandex Cloud → сервисные аккаунты → API-ключи, отзовите старый
и создайте новый. Используйте только новый ключ дальше — он больше не
хранится в файле, а передаётся через переменные окружения хостинга.

## Деплой на Render.com (Docker, бесплатный вариант)

1. Положите папку `ai-backend` в свой GitHub-репозиторий — например,
   рядом с папкой `website`, в корне репозитория.
2. Зайдите на render.com, зарегистрируйтесь (можно через GitHub).
3. **New → Web Service** → выберите свой репозиторий.
4. Render сам увидит `Dockerfile` в папке — укажите:
   - **Root Directory**: `ai-backend`
   - **Runtime**: Docker (определится автоматически по Dockerfile)
5. В разделе **Environment** добавьте переменные:
   - `YANDEX_API_KEY` = ваш новый ключ
   - `YANDEX_FOLDER_ID` = ваш folder ID
6. Нажмите **Create Web Service** и дождитесь деплоя (несколько минут,
   Flet собирает свой веб-клиент — это не мгновенно).
7. Скопируйте адрес вида `https://ваш-сервис.onrender.com` — это и есть
   ссылка, которую нужно вписать на сайте.

Бесплатный тариф Render "засыпает" после ~15 минут без запросов —
первое открытие после паузы может занимать до минуты.

## Подключение к сайту

В файле `website/static/js/ai_agent.js` впишите адрес в `endpoint`:

```js
const AI_AGENT_CONFIG = {
  endpoint: 'https://ваш-сервис.onrender.com',
};
```

Закоммитьте и запушьте — на сайте появится рабочее окошко агента.

## Локальная проверка перед деплоем

```
pip install -r requirements.txt
export YANDEX_API_KEY=ваш_ключ        # на Windows: set YANDEX_API_KEY=ваш_ключ
export YANDEX_FOLDER_ID=ваш_folder_id
python flet_app.py
```

Откройте `http://localhost:8000` в браузере — должно появиться то же
окно, что и в десктопной версии.
