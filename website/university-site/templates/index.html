Как устроен сайт

  1. Данные о мероприятиях и расписании хранятся в файлах data/events.json и data/schedule.json.
  2. Скрипт build.py на Python собирает из них статичные HTML‑страницы.
  3. GitHub Actions автоматически пересобирает и публикует сайт при каждом изменении.
